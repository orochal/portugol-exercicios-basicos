# Algoritmos em Portugol

Lista de exercícios básicos de lógica de programação resolvidos em **Portugol**, feitos no [Portugol Webstudio](https://portugol-webstudio.cubos.io/).

## Exercícios

| # | Arquivo | Enunciado |
|---|---------|-----------|
| 1 | `01-antecessor-sucessor.por` | Lê um número inteiro e imprime o antecessor e o sucessor |
| 2 | `02-kmh-para-mh.por` | Converte velocidade de Km/h para m/h (`R = V * 0,62`) |
| 3 | `03-salarios-minimos.por` | Calcula quantos salários-mínimos um usuário ganha (mínimo de R$ 1320,00) |
| 4 | `04-fahrenheit-celsius.por` | Converte temperatura de Fahrenheit para Celsius |
| 5 | `05-volume-caixa.por` | Volume de uma caixa retangular (`comprimento * largura * altura`) |
| 6 | `06-volume-cilindro.por` | Volume de um cilindro (`π * r² * h`) |
| 7 | `07-consumo-combustivel.por` | Consumo de combustível em Km/L |
| 8 | `08-pecas-ipi.por` | Valor total de duas peças com acréscimo de IPI |
| 9 | `09-idade-em-dias.por` | Converte idade (anos, meses e dias) para dias |
| 10 | `10-segundos-hms.por` | Converte segundos para horas, minutos e segundos |

## Observações

- **Exercício 4:** a fórmula do enunciado, `F = (C × 9/5) + 32`, converte de Celsius para Fahrenheit. Como o exercício pede o contrário, foi isolado o C: `C = (F - 32) × 5/9`.
- **Exercício 9:** considera ano com 365 dias e mês com 30 dias.
- **Exercício 6:** usa a constante `PI` da biblioteca `Matematica`.

## Como executar

1. Acesse o [Portugol Webstudio](https://portugol-webstudio.cubos.io/).
2. Abra ou cole o conteúdo de um dos arquivos `.por`.
3. Clique em executar.
